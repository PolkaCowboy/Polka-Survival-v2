# RDR2 C++ mod template

A bare mod skeleton for use with [ScriptHookRDR2 V2](https://www.nexusmods.com/reddeadredemption2/mods/1472). Contains the additional methods documented on the nexus page along with a current natives.h generated from [https://alloc8or.re/rdr3/nativedb/](https://alloc8or.re/rdr3/nativedb/)

Preconfigured with some basic debug logging and .ini reading/writing via [SimpleIni](https://github.com/brofield/simpleini).
